# Security Policy

## Supported Versions
Security updates are provided for the latest major release. Older versions will receive critical backports on a case-by-case basis.

## Vulnerability Disclosure
If you discover a security vulnerability within the Application Orchestration Platform, please send an e-mail to our security team. Do not open a public issue on GitHub for unpatched vulnerabilities.

- **Email:** `security@example.com` (Note: Update to actual contact)
- **Response Time:** We will acknowledge receipt of your vulnerability report within 48 hours.

## Embargo and Coordinated Disclosure
We ask that you allow us 90 days to remediate the vulnerability before publicly disclosing it. For critical issues, we aim to deploy a fix within 24 hours.

## Safe Harbor
We will not take legal action against security researchers who discover vulnerabilities and report them to us in good faith, provided they comply with this policy and do not compromise user data.

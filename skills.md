# Skills

Repository-related skills and design references.

- project-setup-info-local: Guidance for scaffolding full project layouts.
- agent-customization: Notes on configuring agents and copilot instructions.
- build-frontend: How to build and run the Angular frontend application.
- start-platform: How to start and stop the platform services with `cli.py`.
- test-backend: How to run backend unit tests for the FastAPI service.
- dashboard-ui: How to develop and maintain the new orchestration dashboard UI, state service, and wizard flow.
- architecture-design: How to maintain the detailed architecture documentation, diagrams, edge-case analysis, and design decisions for the platform.
- backend-api: Implement, test, and evolve the FastAPI backend, storage layer, and API contracts for the orchestration platform.
- auth-and-access: Work with Keycloak, OAuth2 Proxy, OpenFGA, and header-based auth flow for local and platform-integrated access control.
- platform-operations: Start, stop, troubleshoot, and maintain the full local platform stack including the CLI, backend, frontend, and asset services.
- documentation-and-mkdocs: Maintain repository docs, architecture explanations, auth notes, and the MkDocs site so the documentation stays aligned with the platform implementation.

When adding new skills or operational runbooks, append entries here and link to specific markdown under `architecture/` or `docs/`.

# Agents

This repository documents the conceptual agents and their intended responsibilities for automation and code-assist workflows.

Defined agents:
- Explore — read-only codebase exploration and Q&A helper for fast context gathering.

Notes about repo layout:
- The repository now includes a minimal Angular scaffold under `frontend/`. The Explore agent may read and summarize frontend files; contributors expanding the frontend should add run/test notes to `frontend/README.md`.

Usage guidance:
- Agents are not runtime processes in this repository; they describe roles used by contributors and automation tools.
